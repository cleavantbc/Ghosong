# Ghosong: Gamified Educational Mobile App 📱

**Role:** Co-Lead Developer (Frontend & Backend Logic)  
**Timeline:** May 2023  
**Platform:** Built via Thunkable (Logic-based Procedural Programming)

## Project Overview
Ghosong is a gamified educational mobile application designed to teach and preserve Indonesian regional culture. Because this application was developed using Thunkable's visual block-based environment, this repository serves as a visual portfolio showcasing the application's interface and the underlying procedural logic blocks I co-engineered.

## Team Credits
This application was developed collaboratively by a team of four:
* **Development Team (Frontend & Backend):** Cleavant Chua & Evans Halim
* **Design Team (UI/UX & Graphic Assets):** Cindy Kusno & Irena Jonathan

## Key Technical Features
* **Real-Time Collision Detection:** Engineered a custom physics and collision logic system for an interactive survival mini-game.
* **Dynamic Quiz Engine:** Developed a responsive quiz system featuring automated scoring and feedback loops.
* **Global State Persistence:** Managed complex state variables across 10+ distinct application screens, ensuring user data and scores transferred seamlessly.
* **Asset Mapping:** Integrated complex data structures (Lists and Arrays) for dynamic asset loading and mapping throughout the application.
